# 🎯 Presentation Loop: MECE 피라미드와 AI 모의 청중 기반 무한 발표 루프 시스템

> **모태 아키텍처**: [Product Loop (Liner Pencil 기반 무한 제품 실험 루프)](./PRODUCT_LOOP_SPEC.md)의 "한 판(Canvas)"과 "무한 플라이휠(Flywheel)" 철학을 프레젠테이션 엔지니어링 전반으로 확장한 전문 설계 명세서입니다.

---

## 1. 프로젝트 비전 및 철학 (Why Presentation Loop?)

### 1.1 기존 AI 슬라이드 도구의 한계: "예쁜 장표 하나"의 착시
- **기존 도구(Gamma, Tome, Beautiful.ai 등)의 한계**:
  단순 키워드나 프롬프트를 넣으면 겉보기에 화려한 템플릿과 슬라이드를 빠르게 뽑아내지만, 실제 비즈니스·의사결정 현장(C-Level 보고, 투자 유치, 프로덕트 싱크)에서는 거의 사용되지 못합니다.
  - **설득 논리의 결핍**: 두괄식 핵심 메시지(Governing Thought)와 이를 뒷받침하는 MECE(상호 배타적, 전체 포괄적) 근거가 부재함.
  - **발표 전체 조망 부재**: 슬라이드 한 장 한 장은 그럴듯하지만, 전체 덱의 논리 흐름(So What? / Why So?)이 끊어짐.
  - **단발성 생성(One-off)**: 발표 자료를 만들고 나면 끝이며, 리허설이나 청중의 날카로운 반박(Objection)을 방어하고 개선하는 루프가 없음.

### 1.2 Presentation Loop의 4대 핵심 철학
1. **피라미드 샤프닝 (Pyramid Sharpening)**:
   - "슬라이드 만들어줘"가 아닌, **맥킨지 피라미드 원칙(Minto Pyramid)**에 따라 **단 하나의 핵심 결론(Governing Thought) + 3대 논리 지지 축(Supporting Pillars) + 데이터 팩트/실측치(Backing Evidence)**를 먼저 뾰족하게 규정.
2. **트리 & 마인드맵 중심 "발표 한 판" (Presentation Canvas)**:
   - 슬라이드를 좌우로 넘겨보는 파편화된 뷰가 아니라, **상위 핵심 결론에서 각 장표로 뻗어나가는 인터랙티브 MECE 논리 트리**를 한눈에 펼쳐놓고 조망.
   - 각 노드를 확장하면 실시간 슬라이드 레이아웃(헤드메시지, 데이터 시각화, 키 비주얼)과 발표자 발화 스크립트(Speaking Notes)를 즉시 확인.
3. **손처럼 쓰는 슬라이드 미세 수정 (Micro-Iteration)**:
   - *"3번 축 장표의 비교표를 3단 가로 카드로 변경해줘"*, *"임원 보고용으로 1장 원페이저 요약본 맨 앞에 추가해줘"*, *"데이터 증거를 Product Loop 실측 지표로 업데이트해줘"*와 같은 자연어 명령으로 즉각 업데이트.
4. **AI 모의 청중(Simulated Audience) 리허설 플라이휠**:
   - 발표 자료를 완성했다고 끝나는 것이 아닙니다. 깐깐한 CFO, 회의적인 CTO, 비즈니스 리더 등 **AI 모의 청중 페르소나가 가상 Q&A 공격과 날카로운 반박을 실행**.
   - 논리적 취약점과 방어율을 측정하여 **보완 장표(Appendix) 및 차기 개정판 덱으로 직결되는 Cycle #N+1 무한 루프** 가동.

## 2. 전체 루프 플로우 (Pipeline)

```text
┌────────────────────────────────────────────────────────┐
│  1. Signal Ingestion (원천 입력 인제스천)                │
│  - Product Loop 산출물(가설, 프로젝트 한 판, 검증 지표)     │
│  - 또는 일반 비즈니스 PRD, 전략 문서, 회의록 원문          │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  2. Pyramid Sharpening (논리 샤프닝)                    │
│  - 핵심 결론 (Governing Thought) 도출                   │
│  - 3대 논리 지지 축 (Supporting Pillars - MECE)         │
│  - 사실 및 지표 증거 (Evidence & Data Points) 매핑       │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  3. Presentation Canvas ("발표 한 판")                  │
│  - 인터랙티브 MECE 논리 트리 노드 구조                   │
│  - 실시간 Tailwind/React 카드형 슬라이드 뷰             │
│  - 슬라이드별 발화 스크립트 & So What / Why So 브릿지   │
│  - 자연어 미세 수정 (Micro-Iteration)                   │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  4. Simulated Audience Rehearsal (AI 모의 청중 리허설)  │
│  - 청중 페르소나 설정 (깐깐한 CFO, 테크니컬 CTO, 사용자 중심 CPO)│
│  - 가상 Q&A 공격 및 논리 비약 반박 시뮬레이션            │
│  - 방어율 및 취약 슬라이드 감지                         │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  5. Lessons-Learned Flywheel (설득 플라이휠)            │
│  - Rehearsal Verdict (Passed / High Risk / Inconclusive)│
│  - What Convinced (설득력 있는 지점)                     │
│  - What Failed (논리적 결함 및 공격당한 지점)            │
│  - 보완 덱 / Appendix 생성 ──────────┐                │
└──────────────────────────────────────┼─────────────────┘
                                       ▼
                          Cycle #N+1 무한 보강 루프 재진입
                                       │
                                       ▼
                  [최종 승인 덱 PPTX / PDF 원클릭 내보내기]
```

## 3. 핵심 모듈별 상세 명세

### 3.1 [Phase 1] Signal Ingestion (원천 신호 인제스천)
- **Product Loop 세션 연동**:
  - `SharpenedHypothesis`(타깃, 문제, 솔루션, 지표) + `ProjectCanvas`(명세, 시안 4개 상태, 플로우) + `LessonLearned`(검증 결과, 성공/실패 요인)를 JSON 스키마로 원클릭 로드.
- **외부 텍스트 인제스천**:
  - 자유 형식의 비즈니스 제안서, IR 피치 초안, 신규 사업 기획안, 개발 로드맵 등 원문 입력 지원.

### 3.2 [Phase 2] Presentation Sharpening (피라미드 가설 샤프닝)
- **맥킨지 피라미드 모델 구조화**:
  1. **Governing Thought (정점 결론)**: 발표 전체를 관통하는 단 하나의 결론 (예: *"Product Loop 도입으로 실험 리드타임을 80% 단축하고 기능 실패율을 1/3로 축소합니다"*).
  2. **3대 지지 축 (MECE Pillars)**:
     - Pillar 1 (Why Now): 기존 방식의 치명적 병목과 시장 기회
     - Pillar 2 (How It Works): 솔루션의 고유한 차별점과 실행 메커니즘
     - Pillar 3 (Impact & ROI): 실측 지표, 투자 대비 효과, 리스크 통제 방안
  3. **데이터 백업 (Evidence)**: 각 축을 수치적으로 뒷받침하는 팩트, 차트 데이터, 파일럿 검증 결과.

### 3.3 [Phase 3] Presentation Canvas ("발표 한 판")
- **트리 & 마인드맵 인터랙션**:
  - 중심 루트 노드(정점 결론)에서 3대 축으로 분기되고, 각 축에서 2~3개의 슬라이드로 확장되는 다이어그램.
  - 마인드맵 노드를 클릭하면 해당 슬라이드의 **풀 와이드 프리뷰**와 **스피킹 노트(발표 스크립트)**가 즉시 연동.
- **슬라이드 레이아웃 엔진**:
  - 비즈니스 장표 표준 레이아웃 지원: `Executive Summary`, `Problem/Solution 2단 대비`, `3-Column Pillar`, `KPI 지표 카드 그리드`, `타임라인 로드맵`, `Architecture/Flow 다이어그램`.
- **내 손처럼 쓰는 미세 수정 (Micro-Iteration)**:
  - *"Pillar 2의 2번째 슬라이드를 가로 타임라인으로 바꿔줘"*
  - *"모든 슬라이드의 강조 색상을 회사 브랜드 블루(#1E40AF)로 통일해줘"*
  - *"Q&A 대비용 Appendix 슬라이드 2장 뒤에 추가해줘"*

### 3.4 [Phase 4] Simulated Audience Rehearsal (AI 모의 청중 리허설)
- **가상 청중 페르소나 라이브러리**:
  - **The Skeptical CFO**: *"이 기능 개발에 투입되는 엔지니어링 리소스 대비 회수 기간(Payback Period)은 몇 개월인가요?"*
  - **The Pragmatic CTO**: *"기존 아키텍처와의 하위 호환성은 어떻게 보장하며, 기술 부채를 유발하지 않나요?"*
  - **The User-Obsessed CPO**: *"실제 사용자가 이 인터랙션을 복잡하게 느끼지 않는다는 정성적 근거가 있나요?"*
- **모의 공방 시뮬레이션**:
  - 슬라이드 덱 전체와 스피킹 노트를 기반으로 AI 페르소나가 슬라이드별 날카로운 질문 3~5개를 생성.
  - 발표자의 기본 답변 논리를 점검하고, 방어 성공 여부(Defended vs Vulnerable)를 자동 채점.

### 3.5 [Phase 5] Lessons-Learned Flywheel & Export
- **레슨런 종합 보고서**:
  - `Persuasion Score` (설득력 점수: 0~100점)
  - `Weakest Slide` (가장 공격받기 쉬운 취약 장표)
  - `Missing Evidence` (보강이 필요한 지표나 데이터)
- **무한 루프 순환 (Cycle #N+1)**:
  - 취약점을 메우는 **보강 장표(Appendix) 자동 삽입** 또는 **논리 전개 순서 재배치**를 적용하여 다음 버전 덱 자동 생성.
- **최종 내보내기**:
  - 고품질 `.pptx` (PowerPoint 호환 파일) 원클릭 다운로드
  - 인쇄 및 배포용 `.pdf` 내보내기
  - 마크다운/HTML 웹 슬라이드 공유 링크 제공
