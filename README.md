# 🔄 Product Loop: Liner Pencil 기반 제품 실험 무한 루프 시스템

> **참고**: [Liner Pencil 제작기: 제품 가설부터 구현·검증까지, 무한 Product Loop 구축](https://liner.com/ko/blog/liner-pencil)의 철학과 아키텍처를 기반으로 구현된 프로젝트입니다.

---

## 1. 프로젝트 목적: "화면 하나"가 아닌 "프로젝트 한 판"과 "무한 루프"

기존 생성형 AI 디자인 도구(v0, Claude Artifacts 등)는 단일 시안(화면 하나)을 빠르게 뽑아내는 데 그쳐, 실제 제품 팀의 협업(PM, 디자이너, 개발자)과 전체 제품 개발 루프의 병목을 해결하지 못했습니다.

**Product Loop**는 다음과 같은 핵심 철학을 실현합니다:

1. **가설 샤프닝 (Sharpening)**:
   - "이 화면 만들어줘"가 아닌, **타깃 사용자, 대조군(Baseline), 핵심 지표(Primary/Guardrail Metric), 통제 변수**를 뾰족하게 규정하는 가설 인터뷰.
2. **프로젝트 한 판 (Project Canvas)**:
   - 기획 **명세(Spec/PRD)** + 상태별 **시안(Screens: Default, Active, Loading, Edge)** + 화면 간 **플로우(Flows)**를 한눈에 펼쳐놓고 리뷰할 수 있는 구조.
3. **내 손처럼 쓰는 미세 수정 (Micro-Iteration)**:
   - 한 판이 나온 후 자연어 명령(*"모바일 하단 탭바로 일괄 교체"*, *"다크 모드 토큰 적용"*, *"세션 만료 엣지 케이스 추가"*)으로 즉시 업데이트.
4. **Figma & 코드 동기화**:
   - 클릭 한 번으로 Figma 플러그인 호환 JSON 스키마 내보내기 및 마크다운 PRD 복사.
5. **레슨런 플라이휠 (Lessons-Learned Flywheel)**:
   - 실험 검증 지표를 분석하여 성공/실패 요인을 도출하고, **멈추지 않고 다음 사이클로 직결되는 3가지 후속 가설을 자동 발굴**하여 무한 루프 구현.

## 2. 전체 루프 플로우 (Pipeline)

```text
┌────────────────────────────────────────────────────────┐
│  1. Signal & Trigger                                   │
│  (지표 이상 감지, 유저 보이스/CS, 슬랙 일상 대화 인입)       │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  2. Sharpening (가설 샤프닝)                             │
│  타깃/대조군/성공지표(CTR, CVR)/가드레일/통제변수 설계     │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  3. Project Canvas ("프로젝트 한 판")                    │
│  - 명세: 기능 요구사항(FR) & 엣지 케이스               │
│  - 시안: Default / Active / Loading / Edge 4개 화면    │
│  - 플로우: 화면 간 트리거 및 전이 조건                   │
│  - 미세조정: "모바일 탭바 교체", "토큰 적용"               │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  4. Rapid Execution & QA                               │
│  - 컴포넌트 코드 배포 & QA 검증 체크리스트              │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  5. Lessons-Learned Flywheel                           │
│  - 실측 지표 판정 (Validated vs Invalidated)            │
│  - What Worked / What Failed 레슨런 정리                │
│  - 다음 사이클 가설 자동 생성 ──────────────┐           │
└─────────────────────────────────────────────┼──────────┘
                                              ▼
                                 Cycle #N+1 무한 루프 재진입
```

## 3. 시작하기 (Quick Start)

### 요구 사양
- Node.js 18+ (Node 22 권장)
- npm 10+

### 설치 및 로컬 서버 구동
```bash
# 의존성 설치 (기완료)
npm install

# 개발 서버 실행
npm run dev

# 빌드 및 프로덕션 실행
npm run build
npm run start
```

브라우저에서 `http://localhost:3000` 접속 후 대시보드를 확인합니다.
